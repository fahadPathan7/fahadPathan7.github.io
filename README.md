# Fahad Pathan's Portfolio

Welcome to the source code for my personal portfolio website! This project is built to showcase my skills, experience, and competitive programming achievements, with a strong focus on clean design, performance, and maintainability.

## 🌐 Live Website

You can view my live portfolio here: [fahadPathan7.github.io](https://fahadPathan7.github.io)

## 🛠️ Technology Stack

This project is intentionally kept simple and lightweight. It relies entirely on native web technologies without the overhead of heavy frameworks:
- **HTML5** for semantic structure
- **Vanilla CSS3** for styling, animations, and responsive design
- **Vanilla JavaScript** for DOM manipulation and interactive elements

## 📁 Project Structure

```text
├── index.html        # Main entry point and page structure
├── style.css         # All styling and responsive breakpoints
├── app.js            # Interactivity and animation logic
├── resources/        # Assets including images, icons, and PDFs
├── AI/               # Documentation and rules specifically for AI agents
└── AGENTS.md         # The global entry point for AI assistants
```
